# @egret-r/resource

> Egret Engine R Resource — Legacy RES Module

Legacy resource management module for Egret Engine R. Provides the classic `RES` API for loading and managing game assets.

Requires `@egret-r/core` as a peer dependency.

## Install

```bash
npm install @egret-r/core @egret-r/resource
```
