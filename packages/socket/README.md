# @egret-r/socket

> Egret Engine R Socket — WebSocket Wrapper

Minimal WebSocket wrapper for Egret Engine R. Provides event-based connection management, binary/text message support, and automatic reconnection.

Requires `@egret-r/core` as a peer dependency.

## Install

```bash
npm install @egret-r/core @egret-r/socket
```
