# @egret-r/assetsmanager

> Egret Engine R AssetsManager — Resource Loading & Management

Asset loading and management module for Egret Engine R. Handles loading queues, progress tracking, caching, and resource lifecycle.

Requires `@egret-r/core` as a peer dependency.

## Install

```bash
npm install @egret-r/core @egret-r/assetsmanager
```
