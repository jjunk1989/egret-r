    Class Texture

    纹理类是对不同平台不同的图片资源的封装 在HTML5中，资源是一个HTMLElement对象 在OpenGL / WebGL中，资源是一个提交GPU后获取的纹理id Texture类封装了这些底层实现的细节，开发者只需要关心接口即可

    See

    • http://edn.egret.com/cn/docs/page/135 纹理集的使用
    • http://edn.egret.com/cn/docs/page/123 获取资源的几种方式
