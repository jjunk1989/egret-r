    Class RadioButtonGroup

    RadioButtonGroup 组件定义一组 RadioButton 组件，这些组件相互排斥；因此，用户每次只能选择一个 RadioButton 组件

    Event.CHANGE 此组中所选 RadioButton 组件的值更改时分派。
