    • bindProperty(host: any, chain: string[], target: any, prop: string): Watcher

      绑定一个对象的属性值到要监视的对象属性上。

      Parameters

      • host: any

        用于承载要监视的属性或属性链的对象。 当 host上chain所对应的值发生改变时，target上的prop属性将被自动更新。

      • chain: string[]

        用于指定要监视的属性链的值。例如，要监视属性 host.a.b.c，需按以下形式调用此方法：bindProperty(host, ["a","b","c"], ...)。

      • target: any

        本次绑定要更新的目标对象。

      • prop: string

        本次绑定要更新的目标属性名称。

      Returns Watcher

      如果已为 chain 参数至少指定了一个属性名称，则返回 Watcher 实例；否则返回 null。

    • bindHandler(
          host: any,
          chain: string[],
          handler: (value: any) => void,
          thisObject: any,
      ): Watcher

      绑定一个回调函数到要监视的对象属性上。当 host上 chain 所对应的值发生改变时，handler 方法将被自动调用。

      Parameters

      • host: any

        用于承载要监视的属性或属性链的对象。

      • chain: string[]

        用于指定要监视的属性链的值。例如，要监视属性 host.a.b.c，需按以下形式调用此方法：bindSetter(host, ["a","b","c"], ...)。

      • handler: (value: any) => void

        在监视的目标属性链中任何属性的值发生改变时调用的事件处理函数。

      • thisObject: any

        handler 方法绑定的this对象

      Returns Watcher

      如果已为 chain 参数至少指定了一个属性名称，则返回 Watcher 实例；否则返回 null。
