    Class MovieClip

    影片剪辑，可以通过影片剪辑播放序列帧动画。MovieClip 类从以下类继承而来：DisplayObject 和 EventDispatcher。不同于 DisplayObject 对象，MovieClip 对象拥有一个时间轴。

    See

    http://edn.egret.com/cn/docs/page/596 MovieClip序列帧动画
