    Class ArrayCollection

    ArrayCollection 类是数组的集合类数据结构包装器，可使用ICollection接口的方法和属性对其进行访问和处理。 使用这种数据结构包装普通数组，能在数据源发生改变的时候主动通知视图刷新变更数据项。

    CollectionEvent.COLLECTION_CHANGE 当 ArrayCollection 更新的的时候会派发此事件。
