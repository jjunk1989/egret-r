    Class LayoutBase

    容器布局基类。若要创建使用 Group 容器的自定义布局，必须扩展 LayoutBase 或其子类之一。

    子类必须实现 updateDisplayList() 方法 （定位 target Group 的子项并调整这些子项的大小）和 measure() 方法 （计算 target 的默认大小）。
