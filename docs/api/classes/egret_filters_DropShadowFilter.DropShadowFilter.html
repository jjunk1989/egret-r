          hideObject?: boolean,
      ): DropShadowFilter

      初始化 DropShadowFilter 对象

      Parameters

      • distance: number = 4.0

        {number} 阴影的偏移距离，以像素为单位。

      • angle: number = 45

        {number} 阴影的角度，0 到 360 度（浮点）。

      • color: number = 0

        {number} 光晕颜色，采用十六进制格式 0xRRGGBB。默认值为 0xFF0000。

      • alpha: number = 1.0

        {number} 颜色的 Alpha 透明度值。有效值为 0 到 1。例如，0.25 设置透明度值为 25%。

      • blurX: number = 4.0

        {number} 水平模糊量。有效值为 0 到 255（浮点）。

      • blurY: number = 4.0

        {number} 垂直模糊量。有效值为 0 到 255（浮点）。

      • strength: number = 1.0

        {number} 印记或跨页的强度。该值越高，压印的颜色越深，而且发光与背景之间的对比度也越强。有效值为 0 到 255。

      • quality: number = 1

        {number} 应用滤镜的次数。暂未实现。

      • inner: boolean = false

        {boolean} 指定发光是否为内侧发光。值 true 指定发光是内侧发光。值 false 指定发光是外侧发光（对象外缘周围的发光）。

      • knockout: boolean = false

        {number} 指定对象是否具有挖空效果。值为 true 将使对象的填充变为透明，并显示文档的背景颜色。

      • hideObject: boolean = false

        {number} 表示是否隐藏对象。如果值为 true，则表示没有绘制对象本身，只有阴影是可见的。默认值为 false（显示对象）。

      Returns DropShadowFilter
