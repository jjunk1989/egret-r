    getVirtualUrl

    • getVirtualUrl(url: string): string

      获取资源文件实际的URL地址。
      由于版本控制实际已经对原来的资源文件的URL进行了改变，因此想获取指定资源文件实际的URL时需要调用此方法。
      在开发调试阶段，这个方法会直接返回传入的参数值。

      Parameters

      • url: string

        游戏中使用的url

      Returns string
